# しままるタイピング

シマエナガをテーマにしたブラウザ用タイピングゲームのMVPです。

## オンラインで遊ぶ

👉 **https://hikavn.github.io/shimamaru-typing/**

GitHub Pages で公開しています。インストール不要、ブラウザですぐに遊べます。

## 遊び方

公開版（上記URL）を開くか、ローカルでは `index.html` をブラウザで開きます。

出題データは `typing-content.json` から読み込みます。単語、長文、記号・数字、苦手キー、ストーリー、チュートリアル手順、週間プランをJSONで管理できます。ファイルの読み込みに失敗した場合は、`game.js` の既定データで動作します。

### 制限時間・経験値・ワシ（全モード共通）

- **制限時間**: すべてのモードに制限時間がつきます（れんしゅう/苦手キー/記号 60秒、ながぶん系 90秒、ストーリー 120秒）。時間切れか、各モードの目標達成で終了します。
- **経験値（速いほど貯まる）**: 正解打鍵ごとに経験値が貯まり、**速く打つほど1打の経験値が増えます**（コンボでも増加）。経験値はレベルになって蓄積され、リザルト画面と画面左上のバッジに表示されます。
- **ワシ（鷲）**: 残り時間が半分を切ると、後ろからワシが追いかけてきます。時間が減るほど近づきます。見た目は差し替え可能なプレースホルダ（`#eagle` 内の `.eagle-art`）で、出現・位置は `game.js` の `updateEagle()` が制御します。
- **他アプリとの経験値共有**: 経験値は「しままる」シリーズ共通の単独モジュール `shimamaru-xp.js`（共有 `localStorage` キー）で管理し、同一オリジンの別アプリ（しままるタスク等）と共有できます。リザルト画面から JSON の書き出し／取り込みも可能です。詳細は [`SHIMAMARU-XP.md`](SHIMAMARU-XP.md)。

### モード一覧

- れんしゅう: 15問または制限時間で終了します。
- ながぶん: 3つの文章を打ち切るか制限時間で終了します。
- チャレンジ: 60秒でスコアを競います。
- ながぶんチャレンジ: 90秒で長文スコアを競います。
- チュートリアル: ホームポジションと指ごとの担当キーを練習します。
- ストーリー: 5つのステージを進めて星評価を集めます。
- 今日のメニュー: 曜日ごとの練習予定をすぐ始めます。
- 毎日のWPMグラフ: 直近14日のWPM推移を表示し、最高/平均を切り替えられます。
- リマインド: 時刻を変えると自動保存され、オンにすると今日の練習を知らせます。
- BGM: 好きな音声ファイルをドラッグ&ドロップして、無限ループ再生できます。
- 苦手キー: ミスが多いキーを含む練習を自動で出題します。
- 記号・数字: 数字、句読点、記号を直接入力で練習します。
- 話題でながぶん: 貼り付けた文章を分割して長文練習に使えます。
- 難易度: やさしい、ふつう、むずかしい。
- `tsu / tu`、`shi / si`、`chi / ti`、`fu / hu`、`nn / n` など複数のローマ字入力に対応しています。

正しいキーを打つとシマエナガが進み、単語を打ち切ると木の実を集めます。ミスをするとコンボがリセットされます。
